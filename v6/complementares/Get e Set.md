# Getters e Setters

Getters e Setters são métodos utilizados em Programação Orientada a Objetos (POO) para acessar e modificar os atributos privados de uma classe. 

- **Getter**: Método responsável por retornar o valor de um atributo privado. Ele permite que o dado seja acessado de forma controlada.
- **Setter**: Método responsável por alterar o valor de um atributo privado. Ele pode incluir validações para garantir que o novo valor seja válido antes de ser atribuído.

O uso de Getters e Setters é uma prática comum para implementar o encapsulamento, protegendo os dados internos da classe e garantindo que sejam manipulados de maneira segura e consistente.
